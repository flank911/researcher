# INF-5 — Детерминизм канонизации: set, bytes, неизвестные объекты

- **Эпик:** E0 — Scaffolding & инфраструктура
- **Статус:** done
- **Зависимости:** INF-3
- **Критический путь:** да

## Описание

Закрыть две дыры в `_canonicalize` (INF-3), через которые `stable_hash` молча
возвращал **разный результат между процессами** — ровно тот отказ, против которого
INF-3 и был сделан.

## Контекст

`_canonicalize` обрабатывал `Mapping`, `Sequence`, `float`, `datetime`, `Enum`,
pydantic и объекты с `__dict__`, а всё остальное отправлял в `str(obj)`. В эту
ветку попадали два типа с нестабильным строковым представлением:

1. **`set` / `frozenset`.** Порядок итерации множества строк зависит от
   `PYTHONHASHSEED`, поэтому `str({'alpha','beta'})` различался между процессами.
   Три прогона одного payload давали три разных хэша:

   ```
   {"tags":"{'delta', 'alpha', 'beta', 'gamma'}"}  60ed242deeadc101
   {"tags":"{'delta', 'gamma', 'alpha', 'beta'}"}  f8db4df3fe067cae
   {"tags":"{'gamma', 'alpha', 'beta', 'delta'}"}  44827d9165eb8515
   ```

2. **Объект без `__dict__`** (например с `__slots__`). Проверка
   `hasattr(obj, "__dict__")` его не ловит, а дефолтный `__repr__` содержит адрес
   в памяти: `"<S object at 0x1096c92d0>"` — новый адрес на каждый запуск.

Практического инцидента не было: сегодня в хэш идут params из сетки (числа и
строки), `dataset_hash` и pydantic-модели. Но отказ **тихий** — любой будущий
параметр-множество обесценил бы `run_hash`, dedupe, resume и cache без единой
ошибки в логе.

## Решение

- `set`/`frozenset` → канонизированный **отсортированный** список.
- `bytes`/`bytearray` → hex-строка (детерминированно, вместо `"b'abc'"`).
- Неизвестный тип без `__dict__`/`model_dump` → **`TypeError`** вместо `str(obj)`.
  Для примитива воспроизводимости громкий отказ лучше тихо нестабильного хэша;
  детерминированная замена вида «имя типа» тоже плоха — она даёт коллизии разных
  объектов.
- Ветка `isinstance(obj, Enum)` задокументирована как достижимая только для
  не-строковых энумов: все энумы домена — `StrEnum`, их перехватывает проверка
  на `str` выше (значение при этом сериализуется корректно).

## Критерии приёмки (DoD)

- [x] `set`/`frozenset` дают одинаковый хэш между процессами (тест в подпроцессах).
- [x] Порядок элементов множества не влияет на результат.
- [x] Объект без `__dict__` не попадает в хэш молча — поднимается `TypeError`.
- [x] `bytes` канонизируются детерминированно.
- [x] Покрыты оставшиеся ветки INF-3: `NaN`, `±Inf`, `Enum`, pydantic, `__dict__`,
      `git_commit_hash` (в репозитории и фоллбэк вне git).
- [x] `hashing.py` закрыт тестами на 100%.
