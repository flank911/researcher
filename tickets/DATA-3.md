# DATA-3 — Валидация данных

- **Эпик:** E1 — Data Core
- **Статус:** done
- **Зависимости:** DATA-2
- **Реализует улучшение:** №13 (гигиена данных)

## Описание

Проверка качества сырых свечей.

- `data/validators.py`: пропуски баров (gap-report по ожидаемому шагу timeframe),
  дубликаты, монотонность времени, нулевые/отрицательные значения, аномалии цены.
- Учёт даты листинга символа (отсутствие данных до листинга — не ошибка).
- Отчёт о качестве (структурированный, сохраняемый).

## Критерии приёмки (DoD)

- [x] На специально «дырявом» датасете отчёт находит все пропуски.
- [x] Дубликаты и немонотонность детектируются.
- [x] Период до листинга не помечается как пропуск.
- [x] Юнит-тесты на каждый тип дефекта.

## Примечание

- `data/validators.py`: `validate_candles(df, timeframe, expected_start=,
  expected_end=, listing_at=, max_return=)` → `ValidationReport` (pydantic,
  frozen, сериализуется в JSON; `save_report` пишет на диск).
- Проверки: gap-report по шагу timeframe (ведущий/внутренние/замыкающий
  пропуски), дубликаты времени, монотонность, нулевые/отрицательные цены,
  отрицательный объём, OHLC-инварианты (`high`=max, `low`=min бара), выбросы
  доходности бар-к-бару (порог `max_return`, дефолт 0.5).
- Листинг: `expected_start` поднимается до `listing_at`, поэтому отсутствие
  данных до листинга не считается пропуском.
