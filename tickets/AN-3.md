# AN-3 — Stability score (robust, вектор)

- **Эпик:** E4 — Analytics
- **Статус:** done
- **Зависимости:** AN-1
- **Реализует улучшение:** №7 (устойчивая метрика стабильности)

## Описание

Надёжная оценка устойчивости параметров вместо хрупкой одиночной формулы.

- `analytics/stability.py`: вектор метрик — `median_return`,
  `positive_slices_ratio`, `worst_slice`, `top_quantile_freq` (с явным определением
  множества: ранг внутри каждого слайса по всем param-комбинациям), `iqr`/дисперсия.
- Защита от деления на ~0 при отсутствии просадки.
- Опциональный композитный score, но основной вывод — вектор + многокритериальное
  ранжирование.

## Критерии приёмки (DoD)

- [x] На синтетике стабильные параметры (Params B) ранжируются выше «пика» (Params A).
- [x] Граничные случаи (нулевая просадка, один слайс) не дают NaN/inf.
- [x] `top_quantile_freq` считается относительно корректного множества (тест).

## Примечание

- `analytics/stability.py` → `stability_vector(table, return_metric=,
  top_quantile=, dispersion_weight=)`: вектор по `param_hash` — `median_return`,
  `positive_slices_ratio`, `worst_slice`, `top_quantile_freq`, `iqr`,
  `return_std`, `n_slices` + композит `stability_score`.
- `top_quantile_freq` — доля слайсов, где параметр в верхнем квантиле **внутри
  своего `time_slice_id`** (множество сравнения — все комбинации данного слайса).
- Композит = `median_return * positive_slices_ratio − dispersion_weight * iqr`
  (в единицах доходности; не делит на просадку/дисперсию → нет NaN/inf при
  нулевом разбросе и единственном слайсе). `rank_by_stability(vector)` —
  ранжирование; основной вывод — вектор для многокритериального отбора.
- Для мультисимвольного/мультитаймфреймового анализа таблицу фильтруют заранее.
