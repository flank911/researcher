# DATA-4 — Каталог датасетов + dataset_hash

- **Эпик:** E1 — Data Core
- **Статус:** done
- **Зависимости:** DATA-2, INF-3
- **Реализует улучшение:** №12 (версионирование данных)

## Описание

Каталог датасетов в SQLite + контентное версионирование.

- Таблица `datasets` (id, name, symbol, timeframe, exchange, market, start_at,
  end_at, data_path, data_hash, created_at).
- Снапшоты по `[symbol, timeframe, range]`.
- Контентный `data_hash` (нормализованный, стабильный) через INF-3.
- Политика дозагрузки: докачка создаёт новую версию датасета, не ломая ссылки
  старых прогонов.

## Критерии приёмки (DoD)

- [x] Одинаковые данные → одинаковый `data_hash`.
- [x] Докачка свечей создаёт новую версию; старая версия остаётся доступной.
- [x] `DatasetRef` разрешается из каталога по id/хэшу.
- [x] Тест на стабильность хэша.

## Примечание

- `data/catalog.py`: `dataset_hash(candles)` — контентный хэш через INF-3
  (`stable_hash`), независим от порядка строк; `DatasetCatalog` (SQLite) с
  `register` / `get` / `get_by_hash` / `versions` / `latest`.
- Версия `id` = хэш от источника (exchange/market/symbol/timeframe) + `data_hash`.
  Регистрация идемпотентна по содержимому; докачка меняет `data_hash` → новая
  строка, старые версии не мутируются (ссылки прошлых прогонов валидны).
- Тесты: `tests/test_dataset_catalog.py` (стабильность/порядок/версионирование).
