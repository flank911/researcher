# WF-2 — WF-оркестратор (out-of-sample)

- **Эпик:** E5 — Walk-forward
- **Статус:** done
- **Зависимости:** WF-1, EXP-2, AN-3
- **Реализует улучшение:** №8 (честная OOS-проверка, без утечки будущего)

## Описание

Walk-forward исполнение.

- На train-окне ищем лучшие параметры (по stability/целевой метрике).
- Параметры выбираются **только из прошлого**; торгуем ими на test-окне.
- Склейка test-сегментов в непрерывную out-of-sample equity.

## Критерии приёмки (DoD)

- [x] На одном символе строится непрерывная OOS-кривая капитала.
- [x] Тест доказывает: выбор параметров не использует данные test-окна (нет утечки).
- [x] OOS-метрики считаются по склеенной кривой.

## Примечание

- `experiments/walk_forward.py` → `run_walk_forward(data, strategy, param_combos,
  folds, execution, timeframe, *, select_by="total_return_pct", min_trades=,
  engine=)` → `WalkForwardResult` (список `FoldSelection`, OOS equity, OOS-метрики).
- На train выбирается лучшая комбинация по числовой метрике `select_by` — только
  по train-окну; выбранной торгуем на test (WF-1 даёт `test.start == train.end`,
  будущее в отбор не течёт). Баланс переносится между фолдами
  (`execution.model_copy(initial_balance=running_balance)`), test-сегменты
  склеиваются в непрерывную OOS-кривую; OOS-метрики — через BT-7 по склейке.
- Анти-утечка доказана тестом: train растёт (выбирается long), test падает (long
  даёт OOS-минус) — будь подглядывание в test, выбрался бы short.
- Зависимость AN-3: `select_by` может быть любой метрикой; стратегия передаётся
  инстансом (слой не импортирует аналитику). Stability-отбор подключается как
  `select_by`/кастомная метрика без изменения оркестратора.
