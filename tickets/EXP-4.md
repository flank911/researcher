# EXP-4 — Хранилище результатов (Parquet + каталог)

- **Эпик:** E3 — Experiment Engine
- **Статус:** done
- **Зависимости:** EXP-2, DATA-4
- **Реализует улучшение:** №11 (запись результатов при параллелизме)

## Описание

Раздельное хранение тяжёлых артефактов и сводных метрик.

- `trades` / `equity_curve` → партиционированный Parquet (`results/`, партиции по run).
- `run_metrics` + индекс ранов (`run_hash`, статус, пути к артефактам, git commit) →
  SQLite (каталог).
- Таблицы согласно схемам из плана (разделы 3.2, 14).
- Запись логов/ошибок run.

## Критерии приёмки (DoD)

- [x] 1000+ ранов пишутся без блокировок БД.
- [x] Чтение по `run_hash` находит метрики и артефакты.
- [x] Тест конкурентной записи (несколько писателей).
- [x] Схема каталога покрывает идентичность рана, статус, пути к артефактам,
  git-commit, `dataset_hash` и все метрики (внешний «раздел 14» плана в репозитории
  отсутствует — реализована согласованная схема `runs` + `run_metrics`, см. модуль).

## Примечание

Зависимость DATA-4 затрагивает EXP-4 только значением `dataset_hash`, которое уже
протянуто как входной идентификатор через `RunSpec` (EXP-3). Каталог результатов
реализован автономно; каталог датасетов (DATA-4) ведёт сами версии данных.
