# ADM-7 — Статический снимок: отчёт, который можно положить рядом с прогоном

- **Эпик:** E10 — Админка
- **Статус:** todo
- **Зависимости:** ADM-4
- **Критический путь:** нет

## Описание

Команда `report`: один самодостаточный HTML-файл с состоянием и результатами
эксперимента на момент выпуска — те же read-model и те же шаблоны, что у
веб-админки, без сервера.

## Контекст

У веб-панели есть свойство, которое для исследования скорее минус: она всегда
показывает **сейчас**. Чтобы вспомнить, что именно видел прогон
[RUN-7](RUN-7.md), сегодня открывают `notebooks/004_first_research.ipynb` — а он
требует venv, ядра и исполнения сверху донизу, и то, что он покажет, посчитано на
сегодняшнем store, а не на тогдашнем. Именно это и случилось: прогон RUN-7
воспроизвести уже нельзя, store дорос до 2026-10-31 ([OPS-2](OPS-2.md)).

Снимок закрывает этот зазор: файл рядом с результатами, с датой и
`git_commit`, который открывается через год без окружения.

Это не замена [ADM-3](ADM-3.md), а его дешёвое продолжение: read-model и шаблоны
уже есть, добавляется только рендер в файл.

## Решение

- `trading-research report --experiment <name> [--out <path>]` — один HTML,
  графики встроены (base64/inline SVG), внешних ссылок и CDN нет.
- Шаблоны — те же, что у веб-админки: вторая верстка не заводится.
- В снимке — дата выпуска, `git_commit`, `dataset_hash`, состояние данных на тот
  момент.
- Holdout попадает в снимок **только если резерв уже раскрыт** в журнале
  ([ADM-5](ADM-5.md)): иначе экспорт стал бы обходом защиты.

## Критерии приёмки (DoD)

- [ ] Файл открывается в браузере без сервера и без сети (тест: в HTML нет
      внешних URL).
- [ ] Шаблоны общие с ADM-3/ADM-4 — отдельной верстки нет.
- [ ] Снимок содержит дату, `git_commit` и состояние данных.
- [ ] Без раскрытого резерва holdout в снимке отсутствует (тест на содержимое).
- [ ] Отчёт по эксперименту без прогонов создаётся и честно говорит, что
      результатов нет.
